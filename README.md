An original, offline card duel. Read the Oracle's open hand, choose when to spend a high value, and match its sigil to double a winning strike. A six carries a Nova bonus.

Play in a desktop browser: click a card once to select it and again to play, or press `1`–`5` and `Enter`. Press `R` to start a new duel.

The game is plain static files in [`game/`](game/). Deterministic title, play, win, and loss states are available with `?shot=title`, `?shot=play`, `?shot=win`, and `?shot=loss`.
